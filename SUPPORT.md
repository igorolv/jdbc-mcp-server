# Support

Use GitHub Issues for general questions, bugs, and feature requests.

Before opening an issue, check:

- the current `README.md`;
- existing open issues;
- your Java and Gradle versions;
- JDBC URL shape, database type, and a minimal query example without secrets.

Do not publish passwords, tokens, real production connection strings, data dumps, or private
database schemas. If the problem is security-related, follow `SECURITY.md`.
